# Guía de contribución

1. Haz un fork o clona el repositorio y crea una rama: `git checkout -b feature/nombre-corto`.
2. Instala dependencias con `npm install`.
3. Haz tus cambios y agrega pruebas para cada funcionalidad nueva.
4. Antes de subir, ejecuta `npm test`. Todas las pruebas deben pasar.
5. Usa mensajes de commit claros, en presente (ej. `Agrego endpoint DELETE`).
6. Sube tu rama y abre un Pull Request hacia `main`.
7. El pipeline debe salir en verde antes de aceptar el PR.
